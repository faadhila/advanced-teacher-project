# Discount Calculator

A Python (Tkinter) app that calculates the final price after a discount.

## Features
- Input: original price, discount (%), and quantity
- Displays the final price clearly
- Input validation with error messages

## Technologies
- Python 3
- Tkinter

## How to Run
1. Install Python 3 from python.org.
2. Download `discount_calculator_gui.py`.
3. Run: `python discount_calculator_gui.py`

## Example
Price 20000, discount 25%, quantity 1 → Final Price: Rp. 15000.00
